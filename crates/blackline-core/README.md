# blackline-core

OPC packages, XML DOM, path-addressed `TreeOp`s, XML formulas
(RFC 5261 / XPath-subset selectors), RFC 5261 patch, XQuery Update
(both compile to `TreeOp`), relationships, content types, and a small
LCS diff. Shared foundation for `blackline-docx`, `blackline-xlsx`,
and `blackline-pptx`. This crate is AI-generated; see the
[repository README](https://github.com/Vector-Legal/blackline#blackline).

```toml
[dependencies]
blackline-core = "0.3"
```
